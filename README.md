## Overview
Quantum-Q is an AI-powered talent intelligence and workforce optimization platform designed to help organizations understand employee capabilities, identify hidden skill potential, and align talent with internal opportunities. The platform analyzes employee experience, project contribution, learning activity, and organizational data to build dynamic skill profiles and support strategic workforce decision-making.

By combining artificial intelligence, data-driven evaluation, and explainable recommendations, Quantum-Q enables employees, managers, and HR teams to make informed decisions related to career growth, internal mobility, learning development, and skill readiness.

## Objective
The primary goal of Quantum-Q is to modernize how organizations assess workforce capabilities by:
- identifying explicit, inferred, and transferable skills,
- matching employees to suitable internal roles and projects,
- analyzing skill gaps and future role readiness,
- recommending personalized learning pathways,
- supporting HR with actionable talent insights.

## Key Features
- AI-powered employee profile analysis
- Hidden and transferable skill discovery
- Dynamic workforce skill profiling
- Internal job and role matching
- Skill gap analysis and career development planning
- Emerging skill forecasting
- AI career assistant for employee guidance
- HR dashboard for talent visibility and strategic planning

## Tech Stack
- Frontend: React, TypeScript, Vite
- Styling: Tailwind CSS
- UI Components: Lucide React
- Backend: Node.js, Express
- AI Integration: Anthropic AI SDK, Google GenAI
- Build Tools: TSX, esbuild
- Architecture: Full-stack web application with modular frontend and backend services

## Project Structure
- `src/` — frontend application components and logic
- `server/` — backend server and data handling
- `backend/auth-service/` — Java-based authentication service
- `README.md` — project documentation

## How to Run

### 1. Install dependencies
```bash
npm install
```

### 2. Configure environment variables
Create a `.env` file and add your AI API key:
```env
ANTHROPIC_API_KEY=your_api_key_here
```

### 3. Start the application
```bash
npm run dev
```

### 4. Production build
```bash
npm run build
npm start
```
